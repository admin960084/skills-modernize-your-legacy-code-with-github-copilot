# COBOL Accounting Application Test Plan

This test plan covers the current interactive COBOL accounting application. Unless stated otherwise, each test starts a new application run so that the initial balance is reset to `1000.00`.

| Test Case ID | Test Case Description | Pre-conditions | Test Steps | Expected Result | Actual Result | Status (Pass/Fail) | Comments |
|---|---|---|---|---|---|---|---|
| TC-001 | Display the account menu | Application is compiled and ready to run | 1. Start the application. | The application displays the Account Management System menu with options 1 (View Balance), 2 (Credit Account), 3 (Debit Account), and 4 (Exit). | To be completed | To be completed | Verify menu labels and option numbering. |
| TC-002 | Verify the initial account balance | New application run | 1. Start the application. 2. Select `1`. | The application displays `Current balance: 1000.00`. | To be completed | To be completed | Confirms the initial in-memory balance. |
| TC-003 | View balance without changing it | New application run | 1. Select `1`. 2. Select `1` again. | Both inquiries display `1000.00`; viewing the balance does not change it. | To be completed | To be completed | Tests the `TOTAL` operation and read-only behavior. |
| TC-004 | Credit the account with a whole-dollar amount | New application run | 1. Select `2`. 2. Enter `100.00`. 3. Select `1`. | The credit succeeds and displays `Amount credited. New balance: 1100.00`. The later balance inquiry displays `1100.00`. | To be completed | To be completed | Tests addition and persistence within the same run. |
| TC-005 | Credit the account with cents | New application run | 1. Select `2`. 2. Enter `25.50`. 3. Select `1`. | The credit succeeds and the balance becomes `1025.50`. | To be completed | To be completed | Confirms two-decimal amount handling. |
| TC-006 | Apply multiple credits sequentially | New application run | 1. Select `2`; enter `100.00`. 2. Select `2`; enter `50.25`. 3. | TC-007 | Debit an amount less than the current balance | New application run | 1. Select `3`. 2. Enter `200.00`. 3. Select `1`. | The debit succeeds and displays `Amount debited. | TC-010 | Verify insufficient funds after a prior transaction | New application run | 1. Select `2`; enter `100.00`. 2. Select `3`; enter `1100.01`. 3. | TC-011 | Apply a credit after a debit | New application run | 1. Select `3`; enter `250.00`. 2. Select `2`; enter `75.25`. 3. Select `1`. | The final balance is `825.25`. | To be completed | To be completed | Tests that debit and credit operations compose correctly. |
| TC-012 | Exit the application | Application is running at the menu | 1. Select `4`. | The application terminates and displays `Exiting the program. Goodbye!`. | To be completed | To be completed | Confirms the main loop stops on option 4. |
| TC-013 | Reject an invalid menu selection | Application is running at the menu | 1. Enter a value outside `1` through `4`, such as `5`. 2. Observe the menu. 3. | TC-014 | Verify balance is not persisted between runs | Complete a run that changes the balance, such as crediting `100.00`, then exit | 1. Exit the first run. 2. Start the application again. 3.
